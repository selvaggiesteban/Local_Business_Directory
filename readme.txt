Plugin de directorio de negocios locales para WordPress.

== Description ==

Un plugin completo para crear y gestionar un directorio de negocios locales en WordPress.

**Características principales:**

* Custom Post Type "Negocio" con URLs amigables (ej: dominio.com.ar/herreria-galvan)
* 3 taxonomías planas: Rubro, Categoría, Zona/Localidad
* Metaboxes nativos para todos los campos del negocio
* Buscador AJAX con filtros por rubro, categoría y zona
* Galería de imágenes por negocio
* Horarios de atención personalizados
* Botón de WhatsApp directo
* Enlace "Cómo llegar" a Google Maps
* Redes sociales integradas
* Menú de administración "Agregar Negocio"
* Plantillas de frontend incluidas
* Responsive y móvil-friendly

**Campos del negocio:**

* Nombre del negocio
* Logo
* Foto de portada
* Frase debajo del nombre
* Dirección
* Teléfono
* WhatsApp con botón directo
* Botón "Cómo llegar" (Google Maps)
* Horarios de atención
* Sección "Quiénes somos"
* Descripción y servicios
* Galería de imágenes
* Instagram y redes sociales

== Installation ==

1. Sube la carpeta `local-business-directory` al directorio `/wp-content/plugins/`
2. Activa el plugin desde el menú "Plugins" de WordPress
3. Configura los permalinks en Ajustes > Enlaces permanentes (selecciona cualquier opción que no sea "Simple")
4. Desde el menú "Agregar Negocio" podés crear tu primer negocio
